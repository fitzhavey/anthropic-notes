# Getting an API key

Course: [Building with the Claude API](https://anthropic.skilljar.com/claude-with-the-anthropic-api) · Module: Accessing Claude with the API

To make a request to the Anthropic API, you'll need a secret API key. This guide walks through creating one.

## Step 1: Navigate to the Anthropic API Console

In your browser, go to <https://console.anthropic.com/> and log in to your Anthropic account.

## Step 2: Click the 'Get API Keys' button

This button is towards the top right of the main dashboard page.

## Step 3: Click the 'Create Key' button

At the top right of the page, find the 'Create Key' button and click it.

## Step 4: Enter a workspace and name for your key

Create the key in workspace 'Default' and enter a name for your key. This name helps you identify the keys you generate — e.g. 'Anthropic Course'.

## Step 5: Copy the key

Your API key will be displayed in a pop-up window. Copy it and hold onto it for the next lesson.

> **Important:** The key is only displayed once. If you accidentally close the window, delete the old key and generate a new one.
